# Run 2026-10-29: the same persona, the same frozen memory, 18 current models

Rerun of [the 2026-08-03 run](2026-08-03-run.md) on the models that replaced the August ones, plus every other frontier family we could reach.
The persona pack is the same private pack, and the memory is frozen at the same snapshot. Three August models were kept unchanged as a ruler:
Claude Fable 5, Claude Opus 5, Claude Haiku 4.5.

Setup: 18 models × 5 tasks = 90 cells, 89 scored. The lost cell is Grok CLI on `t3-memory-conflict`: instead of answering, Grok
replied that it would "check this order against your own decisions first" and stopped. It is excluded, not scored as zero.
One `prompt_hash` per task across all 18 models proves the envelope is identical. Claude models ran through Claude Code. OpenAI models ran through Codex CLI:
the default once, then `gpt-6-astra` and `gpt-6.1-sol` with reasoning effort `high`. Grok ran through Grok CLI. Every other model ran through
OpenRouter with reasoning effort `high` requested, using the same neutral system line the Claude calls get. The judges are the same 3-lens panel
(Claude Sonnet 5: operations / skeptic / editor), all 18 answers to a task shown side by side, the order rotated per judge.
Cross-vendor control comes from two single judges in the skeptic lens: Gemini (`google/gemini-4-argon`) and GPT (Codex CLI default). Score = mean over five rubric axes (1–5).
"TOTAL" is the August scoring: the median of each rubric axis across judges and tasks, then the mean of the five axis medians. It is not a median of per-answer totals. "mean" is the plain mean over all panel verdicts and breaks TOTAL's ties. All 445 verdicts scored all five axes.

Changes since August, all of which can move numbers:
- Gemini runs through OpenRouter, not Gemini CLI (no CLI license on this node).
- `--setting-sources project` added to every Claude call: without it a user-level hook (a timestamp line) leaked into answers.
- Work directory moved outside the vault path. Grok still reads a `CLAUDE.md` it finds; recorded, not fixed.
- CLI versions still unpinned; the field grew from 7 to 18, and judges compare answers side by side.

## Calibration: the ruler moved

Same models, same pack, same prompt, same judges. On the August scoring, Opus 5 went 4.60 → 4.40, Fable 5 went 4.80 → 4.00 and Haiku 4.5 went
2.80 → 2.40. Judges score all answers to a task side by side, so a field of 18 strong models pulls older ones down. **Read any difference
under about 0.8 between this run and August as noise.** Within-run order is what this run can say.

## What the run says

1. **Fable 5.1 is first** on the Claude panel and on the Gemini control. Haiku 4.5 is last on both of those. The GPT control puts it second-to-last, above Gemini 4 Argon.
2. **The panel does not just prefer its own family.** Gemini 4 Argon is third, ahead of Opus 5.5 and Sonnet 5.5, and GLM 5.3 is fifth.
3. **More reasoning did not buy more character.** Codex with `gpt-6-astra` and `gpt-6.1-sol` at `high` effort scored below the Codex default.
   All three judges wrote the same thing in different words: "consultant tone", "a table instead of an argument", "no pushback".
4. **Memory-conflict still breaks the weakest.** Haiku 4.5 again refuses to plan and never cites the memory entry that contradicts the new fact
   (all three judges, independently). DeepSeek V4 Pro "explicitly refuses to argue and gives in", and it invents a document ID along the way.
5. **Fabrication did not go away.** In their free-text reasons the panel judges flagged invented facts most often in three answers: Gemini 4 Argon, Sonnet 5.5 and Grok,
   each in 5 of 15 verdicts (a keyword count over the reasons, a rough measure). Fable 5.1 was flagged in 3.

Spearman rho on per-model means, panel vs Gemini: **0.82 (no Gemini participants 0.84)**. Panel vs GPT: -0.11 (no OpenAI participants 0.24). Gemini vs GPT: 0.19. August, panel vs Gemini: 0.839.

Read straight: **the GPT judge put all three OpenAI participants in its top three, and the Claude panel put the same three 14th–16th.**
The Gemini judge did not do the same for its own family: it scored Gemini 4 Argon 3.92, below the panel's 4.21, and its own top three are all Claude models.
A judge from a participant's own family can be a control, but you have to check that, not assume it.

## Limitations

Everything from August applies: one persona in Russian, single-turn, LLM judges, unpinned CLIs. In addition: one run per cell, so there is no
variance estimate, and the calibration drift is as large as most differences. OpenRouter routes to different providers for the same model.
There is one control judge per vendor, with one lens each.
